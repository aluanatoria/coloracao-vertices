Algoritmo para coloracao de vertices
Atualmente usando uma heuristica gulosa
O arquivo de instancia esta organizado da seguinte forma:
A primeira linha indica a quantidade de vertices e arestas, respectivamente;
As proximas linhas indicam as arestas(u,v).
Criei a estrutura do grafo utilizando lista de adjacencia, visto que a operacao amis realizada é a de verificacao dos vertices adjacentes, e a estrutura de lista faz isso de forma mais rapida.
